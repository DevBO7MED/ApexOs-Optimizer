# ApexOs Optimizer v1.0.0
<img width="1593" height="1039" alt="Screenshot 2026-05-17 18-17-16" src="https://github.com/user-attachments/assets/cf885dde-7b45-482c-a660-14abc68d7362" />


ApexOs Optimizer is a powerful, lightweight, and interactive command-line interface (CLI) utility built in Python. It is specifically designed to debloat, tweak, and optimize Windows 10 and Windows 11 systems to maximize gaming performance, eliminate input lag, and free up valuable system resources.

Built with a visually striking, color-coded terminal layout using the rich library, this tool categorizes system tweaks into clear risk levels so you can optimize your OS safely and confidently.

---

## Key Features

### Low Risk Optimization (Safe for Everyone)
* System Cleanup: Purges Windows temporary files and flushes DNS cache instantly.
* Gaming Boost: Enables Windows Game Mode and disables GameBar DVR to increase FPS.
* Privacy Control: Disables telemetry, location tracking, advertising ID, and Cortana search.
* Notification Control: Blocks Windows error reporting and intrusive system tips/spotlight.
* Network Tweaks: Easily switch to high-performance DNS servers (Google DNS or CloudFlare).

### Medium Risk Tweaks (System Debloating)
* Privacy Hardening: Blocks Microsoft telemetry hosts directly via the hosts file and firewall.
* Unused App Removal: Completely uninstalls Microsoft Edge, OneDrive, Windows Mail, and Internet Explorer.
* Update Control: Temporarily pauses/stops Windows Update services.

### High Risk Actions (Advanced Users Only)
* Deep Service Debloat: Completely disables or removes deeply embedded Windows services and scheduled tasks.
* Security Control: Disables or deletes Windows Defender (Antivirus) for maximum resource liberation.

---

## Built-With & Technical Highlights
* Beautiful CLI: Uses animated progress bars and completion status panels instead of messy command-line text walls.
* Safe Modifications: Automatically creates backups of critical configuration files (like the hosts file) before performing modifications.
* Automated PowerShell Unlinking: Uses robust PowerShell scripting under the hood to completely unprovision and remove native Windows bloatware packages for all users.
